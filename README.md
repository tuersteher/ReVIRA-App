# ReVIRA

ReVIRA is an information source for the MÁV network. It's based on the wonderful trainboard departure/arrival board app. It is supposed to bring back the rich information of MÁV's former ELVIRA engine  by a clear user interface that is strongly inspired by the Danish "Mit Tog".


## Run this code
You can run this application locally by simply downloading the newest source files and opening it in a web browser of your choice.
It's just JS :)

You need an internet connection to fetch data.


## Contribution
If you wish to contribute to this project, please feel free to do so. However, it's important to keep in mind that the primary goal of this project is to faithfully replicate the "Mit-Tog" WebApplication offered by BaneDanmark ([Reference](https://www.mit-tog.dk/en)) and adding a routing function.

Therefore, if you intend to make functional or visual changes that deviate from the original purpose, consider creating your own project using the code provided here.

```
Please be aware that one of the significant advantages of this application
is its ability to run locally in a webbrowser without requiring a complicated setup.
Preserving this functionality would be highly appreciated :)
```
